**CryptoJar.cc** is a Discord-verified crypto wallet and tip bot. Communities use it to send tips, airdrops, redpackets and game drops in any channel, with **0% fees on tips** and **no wallet setup**: no browser extension and no seed phrase.

## What CryptoJar does

- **Tipping:** tip one member, a role or a whole channel, in coins or in dollars (`jtip @friend $1 sol`).
- **Drops & games:** airdrops, redpackets, phrase drops, trivia and math drops with crypto prizes.
- **Personal wallet:** deposit and withdraw privately in DMs with the bot. Only the network fee applies to withdrawals.
- **Server tools:** server stats and leaderboards, XP rank roles and automod. Verified by Discord with all privileged intents.
- **Server store:** sell and buy Discord roles for crypto.
- **For projects:** list your token and put it in front of every CryptoJar user.

Supported networks include Solana, Ethereum, Base, Polygon, BNB Chain, Tron, WAX, Cronos and many custom chains.
See them all, with live prices, at **[new.cryptojar.cc/assets](https://new.cryptojar.cc/assets)**.

## Get started

1. [Add CryptoJar to your Discord server](https://discord.com/oauth2/authorize?client_id=1414376186024296638), or join a server that already uses it.
2. Deposit in a DM with the bot: `jdeposit sol`
3. Tip and drop: `jtip @friend $1 sol`, `jairdrop $5 sol 10m`

Every command is explained at **[new.cryptojar.cc/commands](https://new.cryptojar.cc/commands)**.
